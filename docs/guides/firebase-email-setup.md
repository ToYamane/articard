# Firebase メール配信改善ガイド（迷惑メール対策）

Firebase デフォルトの認証メールは `noreply@articard-ff673.firebaseapp.com` という共有ドメインから送信されるため、迷惑メールに振り分けられやすい。以下の手順で改善する。

## レベル1: テンプレートのカスタマイズ（5分・即時可能）

**Firebase Console** → Authentication → Templates

### メールアドレスの確認テンプレート

1. テンプレートの編集アイコンをクリック
2. 以下を設定:
   - **送信者名**: `Articard`
   - **返信先アドレス**: `support@articard.app`（実在するアドレス）
   - **件名**: `Articard - メールアドレスの確認`
   - **本文**:

     ```
     Articard をご利用いただきありがとうございます。

     以下のリンクをクリックして、メールアドレスの確認を完了してください。

     %LINK%

     このメールに心当たりがない場合は、このメールを無視してください。

     Articard チーム
     ```

### パスワードリセットテンプレート

1. 「パスワードのリセット」テンプレートの編集アイコンをクリック
2. 以下を設定:
   - **送信者名**: `Articard`
   - **返信先アドレス**: `support@articard.app`
   - **件名**: `Articard - パスワードのリセット`
   - **本文**:

     ```
     パスワードのリセットがリクエストされました。

     以下のリンクをクリックして、新しいパスワードを設定してください。

     %LINK%

     このリクエストに心当たりがない場合は、このメールを無視してください。
     パスワードは変更されません。

     Articard チーム
     ```

## レベル2: カスタムドメイン設定（30分・最もコスパが良い）

### 前提条件

- `articard.app` ドメインの DNS レコードを編集できること

### 手順

1. **Firebase Console** → Authentication → Templates → 任意のテンプレートの編集アイコン → 下部の「ドメインをカスタマイズ」
2. カスタムドメインを入力: `auth.articard.app`
3. Firebase が表示する DNS レコードを設定:
   - **TXT レコード**: ドメイン所有権の確認
   - **CNAME レコード**: Firebase のメールサーバーへのポイント
4. DNS 伝播を待つ（数分〜数時間）
5. Firebase Console で「確認」をクリック

### 効果

- メールの From が `noreply@auth.articard.app` になる
- 自ドメインからの送信として認識され、信頼性が向上

## レベル3: カスタム SMTP サーバー（最も効果が高い）

レベル2で迷惑メール問題が解消しない場合のみ実施。

### 推奨サービス

| サービス     | 無料枠   | 特徴                |
| ------------ | -------- | ------------------- |
| **Resend**   | 100通/日 | モダンAPI、設定簡単 |
| **SendGrid** | 100通/日 | 業界標準、実績豊富  |
| **Brevo**    | 300通/日 | 無料枠が最大        |

### 手順

1. メールサービスのアカウント作成、送信ドメイン（`articard.app`）を登録・認証
2. DNS に SPF/DKIM/DMARC レコードを追加（サービスが指示する値）:
   - **SPF**: `v=spf1 include:<サービスのドメイン> ~all`
   - **DKIM**: サービス提供の公開鍵を TXT レコードに追加
   - **DMARC**: `v=DMARC1; p=quarantine; rua=mailto:admin@articard.app`
3. **Firebase Console** → Authentication → Templates → SMTP 設定:
   - サーバー: サービスの SMTP ホスト
   - ポート: `587`（TLS）
   - ユーザー名/パスワード: サービスの API キー
   - 送信元: `noreply@articard.app`
4. テスト送信で確認

## 検証方法

1. 新規アカウントを登録してメール受信を確認
2. Gmail、Yahoo メール、Outlook 等複数のプロバイダーでテスト
3. [mail-tester.com](https://www.mail-tester.com/) でスコアを確認（7/10 以上が目標）
