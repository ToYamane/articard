# カード表面フレームのSVGプログラム生成化

**日付**: 2026-02-09

## 概要

カード表面のフレームをAI生成PNGからSVGプログラム生成に全面切り替え。
全レアリティで統一構造を持ち、色・装飾の段階的変化でレアリティを差別化するデザインに改良。

## 背景・動機

- 旧フレーム（PNG）はレアリティ間でスタイルがバラバラ（アールヌーボー/SF/バロック混在）
- 「額縁」的で TCG カードらしくない
- Legend = SuperRare のコピーで最高レアリティの固有性がなかった
- PNG透明性の品質問題（Rareフレームのエッジが粗い）

## 変更ファイル

`src/lib/card/image-composer.ts` — 1ファイルのみ

## 設計

### 合成フロー

```
背景(#1a1a2e) → イラスト(全面カバー) → フレームSVG → タイトルSVG
```

### カードレイアウト（全レアリティ共通構造）

```
┌────────────────────────────────┐
│          outer border          │  ← レアリティ色ボーダー（6〜12px）
│  ┌──────────────────────────┐  │
│  │ ▓▓▓ キーワード名 ▓▓▓▓▓▓ │  │  ← 上部グラデーション帯（半透明暗色→透明）
│  │                          │  │
│  │      ILLUSTRATION        │  │  ← フルブリードイラスト（512x768）
│  │                          │  │
│  │                          │  │
│  └──────────────────────────┘  │
└────────────────────────────────┘
      ↑ inner line (rare以上)
      ↑ corner decorations (全レアリティ)
      ↑ accent line (rare以上)
```

### レアリティ別デザイン

| 要素 | Common | Rare | Super Rare | Legend |
|------|--------|------|------------|--------|
| **ボーダー幅** | 6px | 8px | 10px | 12px |
| **ボーダー色** | #9CA3AF (gray) | #3B82F6 (blue) | グラデーション (紫) | グラデーション (金) |
| **角丸** | rx=8 | rx=10 | rx=12 | rx=14 |
| **上部帯** | 70px, 黒0.6 | 80px, 黒0.65 | 85px, 黒0.7+紫ティント | 90px, 黒0.7+金ティント |
| **インナーライン** | なし | 1.5px, inset 16 | 2px, inset 20 | 2.5px, inset 24 |
| **コーナー装飾** | L字ブラケット | L字+ドット | ダイヤジェム+装飾ライン | 装飾コーナー+スクロール+ジェム |
| **アクセントライン** | なし | 下部中央 | 下部中央 | 下部中央 |
| **上部オーナメント** | なし | なし | なし | クラウン型（3頂点+ジェム） |
| **下部グロー** | なし | なし | なし | 30px金色グラデーション |

### タイトルテキスト（全レアリティ共通）

- フォントサイズ: 30px
- y座標: 48
- ストローク: 黒3px (paint-order: stroke)
- フォント: 既存の重み付きランダム選択

タイトル色のみレアリティ別:
- Common: #D1D5DB / Rare: #93C5FD / Super Rare: #C4B5FD / Legend: #FDE68A

## 主な変更点

1. **`FRAME_CONFIG` → `CARD_DESIGN`**: PNGパスベース設定をSVG描画パラメータに置換
2. **`generateFrameSvg()` 新規追加**: レアリティに応じたフレームSVGを動的生成
3. **`createCardFront()` 簡略化**: PNG読み込み+フォールバック → SVG合成のみ
4. **`import fs` 削除**: PNGファイル読み込みが不要に
5. **タイトルからカード番号削除**: 表面はキーワード名のみ（番号は裏面に表示済み）

## 変更しなかったもの

- `createCardBack()` — 裏面は変更なし
- `public/frames/` — PNGファイルは残存（未使用、別途クリーンアップ可）
- `src/lib/constants/rarity-config.ts` — UIで参照されるため変更なし
- フロントエンドコンポーネント — サーバー側合成済み画像を返すため変更不要
