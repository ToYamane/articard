# 02. 記事生成機能

## 2.1 機能概要

ユーザーが入力したテーマ（30字以内）から、800文字程度の学習記事をAI生成する。

## 2.2 入力仕様

### テーマ入力

| 項目 | 仕様 |
|------|------|
| 最小文字数 | 2文字 |
| 最大文字数 | 30文字 |
| 禁止文字 | 特殊文字（絵文字は許可） |
| 入力例 | 「万有引力の発見」「恐竜の絶滅」「光合成のしくみ」 |

### バリデーションフロー

```
ユーザー入力
    │
    ▼
┌─────────────────┐
│ 文字数チェック   │ ─── NG ──▶ エラー表示
│ (2-30字)        │
└─────────────────┘
    │ OK
    ▼
┌─────────────────┐
│ OpenAI          │ ─── 違反 ──▶ エラー表示
│ Moderation API  │            「このテーマでは生成できません」
└─────────────────┘
    │ OK
    ▼
記事生成処理へ
```

## 2.3 記事生成仕様

### 出力仕様

| 項目 | 仕様 |
|------|------|
| 文字数 | 800文字（±50文字許容） |
| 構成 | 自由形式（AIに任せる） |
| 難易度 | テーマに応じて自動調整 |
| 言語 | 日本語 |

### 難易度自動調整の例

| テーマ例 | 推定難易度 | 文体 |
|---------|-----------|------|
| 「うさぎの耳はなぜ長い？」 | 子ども向け | やさしい言葉、ひらがな多め |
| 「量子コンピュータの原理」 | 大人向け | 専門用語含む、論理的 |
| 「織田信長の天下統一」 | 一般向け | バランスの取れた文体 |

### OpenAI プロンプト設計

```
システムプロンプト:
あなたは教育コンテンツの専門ライターです。
以下のルールに従って学習記事を生成してください。

ルール:
1. 文字数は800文字程度（750-850文字）
2. テーマに応じた適切な難易度で執筆
3. 正確な情報のみを含め、不確かな情報は含めない
4. 学習意欲を引き出す興味深い内容にする
5. 構成は自由だが、読みやすさを重視
6. 見出しや箇条書きは使用しない（本文のみ）

ユーザープロンプト:
テーマ: {user_input}
上記のテーマについて、学習記事を生成してください。
```

## 2.4 コンテンツモデレーション

### OpenAI Moderation API

入力テーマに対して事前にModerationチェックを実施。

```typescript
// フィルター対象カテゴリ
const blockedCategories = [
  "sexual",

  "hate",
  "hate/threatening",

  "self-harm",
  "self-harm/intent",
  "self-harm/instructions",
  "violence",
  "violence/graphic",

```

### カスタムフィルター（追加）

Moderation APIでは検出できない不適切テーマ:

```typescript
const customBlockedKeywords = [
```

## 2.5 エラーハンドリング

| エラー種別 | ユーザー表示 | 対応 |
|-----------|-------------|------|
| 文字数超過 | 「30文字以内で入力してください」 | フロントでブロック |
| Moderation違反 | 「このテーマでは記事を生成できません」 | API呼び出し前にブロック |
| API Rate Limit | 「しばらく待ってから再度お試しください」 | リトライ or 待機 |
| API Error | 「生成に失敗しました。再度お試しください」 | ログ記録、リトライ |
| Timeout | 「生成に時間がかかっています」 | 最大30秒待機 |

## 2.6 データ保存

生成された記事は以下の情報とともにDBに保存:

```typescript
interface Article {
  id: string;           // UUID
  userId: string;       // 生成したユーザー
  theme: string;        // 入力テーマ
  content: string;      // 生成された記事本文
  createdAt: Date;      // 生成日時
  
  // メタデータ
  openaiModel: string;  // 使用モデル
  tokenUsage: number;   // トークン消費量
}
```
