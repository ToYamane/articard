# 08. 画面遷移図

## 8.1 全体画面遷移図

```mermaid
flowchart TB
    subgraph 未認証
        LP[ランディングページ]
        Login[ログイン画面]
        Register[新規登録画面]
        SharedCard[共有カード閲覧]
    end

    subgraph 認証済み
        Home[ホーム画面]
        
        subgraph 記事生成フロー
            ThemeInput[テーマ入力]
            ArticleLoading[記事生成中]
            ArticleView[記事表示]
        end
        
        subgraph カード生成フロー
            CardLoading[カード生成中]
            CardResult[カード完成]
        end
        
        subgraph コレクション
            Collection[コレクション一覧]
            CardDetail[カード詳細]
            ShareModal[共有モーダル]
        end
        
        subgraph 設定
            Settings[設定画面]
            EditNickname[ニックネーム編集]
            DeleteAccount[アカウント削除確認]
        end
    end

    %% 未認証フロー
    LP --> Login
    LP --> Register
    LP --> SharedCard
    Login --> Home
    Register --> NicknameSetup[ニックネーム設定]
    NicknameSetup --> Home
    SharedCard --> Login

    %% メインフロー
    Home --> ThemeInput
    Home --> Collection
    Home --> Settings
    
    %% 記事生成フロー
    ThemeInput --> ArticleLoading
    ArticleLoading --> ArticleView
    ArticleView --> ThemeInput
    ArticleView --> CardLoading
    
    %% カード生成フロー
    CardLoading --> CardResult
    CardResult --> Collection
    CardResult --> ArticleView
    
    %% コレクションフロー
    Collection --> CardDetail
    CardDetail --> ShareModal
    CardDetail --> ArticleView
    
    %% 設定フロー
    Settings --> EditNickname
    Settings --> DeleteAccount
    DeleteAccount --> LP
```

## 8.2 画面一覧

| 画面ID | 画面名 | パス | 認証 |
|--------|--------|------|------|
| LP | ランディングページ | / | 不要 |
| Login | ログイン | /login | 不要 |
| Register | 新規登録 | /register | 不要 |
| NicknameSetup | ニックネーム設定 | /setup | 必要 |
| Home | ホーム | /home | 必要 |
| ThemeInput | テーマ入力 | /create | 必要 |
| ArticleView | 記事表示 | /articles/:id | 必要 |
| CardResult | カード完成 | /cards/:id/new | 必要 |
| Collection | コレクション | /collection | 必要 |
| CardDetail | カード詳細 | /cards/:id | 必要 |
| Settings | 設定 | /settings | 必要 |
| SharedCard | 共有カード | /share/:id | 不要 |

## 8.3 詳細画面遷移

### 8.3.1 認証フロー

```mermaid
flowchart LR
    subgraph ログイン
        L1[ログイン画面] --> L2{認証方式}
        L2 -->|Google| L3[Google OAuth]
        L2 -->|Apple| L4[Apple OAuth]
        L2 -->|メール| L5[メール入力]
        L5 --> L6[パスワード入力]
        L3 --> L7{初回?}
        L4 --> L7
        L6 --> L7
        L7 -->|Yes| L8[ニックネーム設定]
        L7 -->|No| L9[ホーム]
        L8 --> L9
    end
```

### 8.3.2 記事・カード生成フロー

```mermaid
flowchart TB
    A[テーマ入力画面] -->|テーマ送信| B{Moderation}
    B -->|OK| C[記事生成中<br/>ローディング]
    B -->|NG| D[エラー表示]
    D --> A
    C --> E[記事表示画面]
    E -->|カード生成| F[カード生成中<br/>ローディング]
    E -->|再生成| A
    F --> G{生成結果}
    G -->|成功| H[カード完成画面]
    G -->|失敗| I[エラー表示]
    I --> E
    H -->|コレクションへ| J[コレクション]
    H -->|もう1枚生成| F
    H -->|別のテーマ| A
```

### 8.3.3 コレクション画面フロー

```mermaid
flowchart TB
    A[コレクション一覧] -->|カード選択| B[カード詳細モーダル]
    A -->|検索| C[検索結果]
    A -->|フィルター| D[フィルター適用]
    C --> A
    D --> A
    B -->|共有| E[共有モーダル]
    B -->|元記事| F[記事表示]
    B -->|閉じる| A
    E -->|SNS選択| G[SNS共有]
    E -->|画像保存| H[ダウンロード]
    E -->|閉じる| B
```
