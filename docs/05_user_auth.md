## 5.6 セッション管理

### Firebase Auth セッション

```typescript
// クライアント側
import { getAuth, onAuthStateChanged } from 'firebase/auth';

const auth = getAuth();

onAuthStateChanged(auth, (user) => {
  if (user) {
    // ログイン状態
    const idToken = await user.getIdToken();
    // API リクエストに idToken を含める
  } else {
    // 未ログイン状態
  }
});
```

### API 認証

```typescript
// サーバー側（API Routes）
import { getAuth } from 'firebase-admin/auth';

const verifyToken = async (req: Request): Promise<DecodedIdToken> => {
  const authHeader = req.headers.get('authorization');
  const token = authHeader?.replace('Bearer ', '');
  
  if (!token) {
    throw new UnauthorizedError('No token provided');
  }
  
  const decodedToken = await getAuth().verifyIdToken(token);
  return decodedToken;
};
```

## 5.12 エラーハンドリング

| エラー | ユーザー表示 | 対応 |
|--------|-------------|------|
| メール重複 | 「このメールアドレスは既に登録されています」 | ログイン画面へ誘導 |
| パスワード弱 | 「パスワードは8文字以上で設定してください」 | 再入力を促す |
| OAuth失敗 | 「認証に失敗しました。再度お試しください」 | リトライ |
| セッション切れ | 「セッションが切れました。再度ログインしてください」 | ログイン画面へ |
| ニックネーム不正 | 「ニックネームは2-20文字で入力してください」 | 再入力を促す |
