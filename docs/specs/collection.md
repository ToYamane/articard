# 04. コレクション機能

## 4.1 機能概要

ユーザーが生成したカードを図鑑形式で表示・管理・検索できる機能。

```

│                                      │

│   姿を現した」                       │
│                                      │

│  📅 生成日: 2025年1月22日            │
│  📖 元記事: 万有引力の発見           │

```

### 表示項目（詳細）

| 項目 | 説明 |
|------|------|
| カード画像 | フルサイズ表示 |
| キーワード | カードの名前 |
| レア度 | 星表示 + テキスト |
| フレーバーテキスト | カードのテキスト |
| 生成日 | カード生成日時 |
| 元記事タイトル | リンク付き |
| 文脈カテゴリ | どのような文脈で生成されたか |

### アクションボタン

- **共有**: SNS共有モーダルを開く
- **元記事を見る**: 生成元の記事を表示
- **削除**: カードを削除（確認ダイアログ付き）

### 削除確認ダイアログ

```
┌────────────────────────────────────┐
│ カードを削除                        │
├────────────────────────────────────┤
│                                    │
│  「りんご」のカードを削除しますか？  │
│                                    │
│  この操作は取り消せません。          │
│                                    │
│  ┌────────────┐  ┌────────────┐   │
│  │ キャンセル  │  │   削除する  │   │
│  └────────────┘  └────────────┘   │
└────────────────────────────────────┘
```

### 削除時の挙動

- カード削除: 該当カードのみ削除（関連記事は残る）
- 記事削除: 記事と紐づく全カードを連動削除
- 削除後はコレクション一覧にリダイレクト
- トースト通知: 「カードを削除しました」

## 4.4 検索・フィルター機能

### テキスト検索

```typescript
interface SearchParams {
  query: string;  // キーワード名で検索
}
```

### フィルター条件

```typescript
interface FilterParams {
  // レア度フィルター
  rarity?: Rarity[];  // 複数選択可
  
  // 日付フィルター
  dateFrom?: Date;
  dateTo?: Date;
  
  // 文脈カテゴリフィルター
  contextCategory?: ContextCategory[];
  
  // ソート
  sortBy: "createdAt" | "rarity" | "keyword";
  sortOrder: "asc" | "desc";
}
```

## 4.6 SNS共有機能

### 共有フロー

```
共有ボタンタップ
    │
    ▼
┌─────────────────┐
│ 共有用画像生成   │ ← カード画像 + 透かし/ロゴ
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 共有先選択      │
│ ・X (Twitter)   │
│ ・LINE          │
│ ・画像保存      │
│ ・リンクコピー  │
└─────────────────┘
```

### 共有用画像仕様

- 元のカード画像をそのまま使用
- 右下にサービスロゴ/透かしを追加（オプション）
- OGP対応のメタデータ付与

### 共有テキストテンプレート

```
【{keyword}】のカードを手に入れた！
{rarity_stars} {rarity_name}

{flavor_text}

#Articard #AIカード
{share_url}
```

### 共有リンク

```
https://example.com/cards/{card_id}

→ 未ログインユーザーでもカード詳細を閲覧可能
→ 「自分も作ってみる」CTAを表示
```

## 4.7 ページネーション

### 無限スクロール

- 初回表示: 20枚
- スクロールで追加読み込み: 20枚ずつ
- ローディングインジケーター表示

```typescript
interface PaginationParams {
  cursor?: string;  // 最後に読み込んだカードID
  limit: 20;
}

interface PaginatedResponse<T> {
  items: T[];
  nextCursor: string | null;
  hasMore: boolean;
  totalCount: number;
}
```

## 4.8 パフォーマンス最適化

### 画像最適化

```typescript
// サムネイル用の最適化画像を別途生成
interface CardImages {
  original: string;    // 512x768 フル画像
  thumbnail: string;   // 128x192 サムネイル
  share: string;       // 1024x1536 共有用高解像度
}
```

### キャッシュ戦略

- サムネイル画像: ブラウザキャッシュ（7日）
- カード一覧: SWR / React Query でキャッシュ
- 検索結果: 短期キャッシュ（5分）
